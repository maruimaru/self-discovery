# 自己理解・診断ひろば

文化祭や授業で気軽に体験できる、アンケート式の自己理解診断サイトです。

質問への回答を通じて、自分の持ち味やチームでの関わり方を振り返り、
仲間との対話や、新しい役割への挑戦につなげることを目的としています。

| --- | ---: | ---: | --- |
| モノづくり判定 | 49問 | 7系統 | 制作チームでの持ち味や関わり方を振り返る |
| スポーツポジション判定 | 35問 | 7系統 | チームスポーツでの関わり方を振り返る |

## 診断について

- 能力や実際の適性を断定するものではありません。
- 結果は、今回の回答に基づく自己理解の目安です。
- 複数の系統が高得点でも、すべて同点でもかまいません。
- 点数が低い役割にも、経験や練習を通じて挑戦できます。
- 役割は結果だけで固定せず、仲間や先生と相談して考えましょう。

## 公開方法

GitHub Pagesを利用します。

- 公開ブランチ：main
- 公開フォルダ：/（root）

## 診断を追加するとき

1. 新しい診断用のフォルダを作ります。
2. 完成した診断HTMLを、そのフォルダ内に index.html として配置します。
3. 入口ページの index.html に、診断へのリンクカードを追加します。
4. スマートフォンでリンクと診断の動作を確認します。

## 更新時の確認

- 設問数と、各系統の質問数が合っていること
- 棒グラフの満点とレーダーの目盛りが合っていること
- 同点結果の一覧から詳細へ進めること
- 詳細ページの画像・棒グラフ・レーダーが表示されること
- 結果一覧への戻りと再診断が動作すること
